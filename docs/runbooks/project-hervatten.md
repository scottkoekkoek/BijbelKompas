# Runbook — App werkt niet meer (project gepauzeerd)

Op het gratis plan zet Supabase het project stil na 7 dagen zonder gebruik. Je data blijft bewaard.

1. Ga naar https://supabase.com/dashboard en open `bijbelkompas-prod`.
2. Klik op **Restore project** / **Resume**. Dit duurt een paar minuten.
3. Open de app opnieuw en log in.

Een gepauzeerd project kan een beperkte tijd worden hervat (zie Supabase-documentatie);
daarna kun je alleen nog een back-up downloaden. Onze eigen back-ups staan los daarvan in GitHub.
